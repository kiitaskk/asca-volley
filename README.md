# Calendrier ASCA 1

Matchs à venir et résultats de l'équipe ASCA 1 (M18 masculin 6×6, Championnat du Maine, saison 2026/2027).

- `index.html` : la page publiée sur GitHub Pages.
- `data.json` : les matchs et le classement, relus sur le site FFvolley.
- `scripts/update.py` : le script qui lit le site FFvolley et met à jour `data.json`.
- `.github/workflows/update.yml` : lance ce script toutes les heures sur GitHub.

Source : [FFvolley – poule 18M](https://www.ffvbbeach.org/ffvbapp/resu/vbspo_calendrier.php?saison=2026%2F2027&codent=PTPL72&poule=18M&division=&tour=&calend=COMPLET&x=37&y=7)
